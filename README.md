# Open Source AI Scikit-learn Classification

This Python example demonstrates a fundamental machine learning workflow using scikit-learn, a popular open-source library. It generates synthetic data, trains a Decision Tree Classifier, and evaluates its performance, illustrating how open-source tools democratize AI development by providing accessible algorithms, models, and datasets. This aligns with the article's emphasis on open source AI's importance.

## Language

`python`

## How to Run

1. Ensure Python 3 is installed.
2. Install necessary libraries: `pip install numpy scikit-learn`
3. Run the script: `python main.py`
